# python quiz


This is my first mini project — a simple command-line quiz game written in Python.

About

The quiz has 15 multiple choice questions, and the order of the questions changes every time the program is run. Each question is paired correctly with its own answer, even after shuffling.

How it works
You answer each question by typing A, B, C, or D.
If you get a question wrong, the correct answer is shown right away.
Your answers are stored in a separate list so they can be compared with the correct answers at the end.
At the end, your score is shown as a percentage, based on how many questions you answered correctly.
